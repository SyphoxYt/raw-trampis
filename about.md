# RawTrampis Pro v4.6.0

RawTrampis Pro is a configurable Geometry Dash 2.2081 / Geode 5.11.2 toolkit for practice, gameplay analysis, and interface customization. It provides searchable category panels, feature settings, custom keybinds, profiles, themes, and animated transitions.

The tabbed panels can be rearranged and their positions are saved when dragging ends. Theme and font refreshes restore the existing panel layout. Theme choices display paired main and accent colors; background blur is animated on the desktop ImGui renderer where supported. Changelog entries track the user-visible release history from v1 through v4.6.0.

Noclip and the cheat indicator are optional, disabled by default, and independently controlled. Noclip keeps ordinary platforms solid. Use gameplay-altering features only where permitted; assisted attempts may not qualify for records or leaderboards.
