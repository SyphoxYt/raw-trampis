# RawTrampis Pro

RawTrampis Pro v4.2.0 is a Geometry Dash 2.2081 / Geode 5.11.2 toolkit for configurable practice and gameplay analysis. It features a searchable, animated multi-panel interface, independently configurable features, multiple themes, and the blue RawTrampis theme.

## Open the menu

Press **Ctrl+N** to toggle the interface. Change the menu key in **Keybinds**. Use the **Interface** tab to select a theme, adjust blur and scale, and control panel layout and animation preferences. Search the menu to find controls; panels can be moved, resized, and scrolled independently.

## Categories

1. Global
2. Level
3. Bypass
4. Player
5. Bot
6. Creator
7. Labels
8. Shortcuts
9. Keybinds
10. Interface
11. Recorder

Features are organized into dedicated categories and keep their individual options. **Noclip** is under Player and defaults off. The cheat indicator is independently configurable in Labels. Do not assume an assisted run qualifies for records or leaderboards; several options change gameplay or progression.

Optional integrations are Globed and the FFmpeg API used by recording. The arbitrary DLL-loading shortcut is intentionally excluded because it can execute external code inside Geometry Dash.
